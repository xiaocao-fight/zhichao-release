# 知潮 · AI 新词雷达

**每天 5 分钟看懂 AI 圈新词。**

知潮是一个**本地优先**的 AI 术语发现工具：它持续追踪几十个可信来源（官方博客、
arXiv、专业媒体、国内外热榜），把正在冒头的 AI 新词自动整理成看得懂的词条卡 ——
一句话释义、原文证据、来源数量、趋势阶段，每一条都能回查出处。

它不看你的聊天记录、不要求注册账号、不把数据传到任何人的服务器。

## 快速开始

1. 下载并解压 `zhichao-windows-x64.zip`
2. 双击 **`启动知潮.bat`**
3. 浏览器自动打开 `http://127.0.0.1:4317`，等几秒，第一批候选词就出现了

首次启动会自动准备内置来源和今日推荐，可能需要一点时间；之后每次打开都是秒级。

## 为什么不一样

- **零配置冷启动** —— 内置 46 个免费来源，打开应用约 5 秒出第一批候选词。
  不用注册、不用选模型、不用填任何密钥。
- **本地优先** —— 数据全部存在本机 SQLite；API 密钥用 Windows 用户级加密保存，
  不进日志、不上云、没有账号体系。
- **证据可回查** —— 每个词条带原文出处；证据不足时如实显示「现有来源不足以确认」，
  不会编一句释义糊弄你。
- **AI 可选，不绑架** —— 免费基础功能（发现、趋势、搜索、收藏、复习）不需要任何
  API 密钥；想要更深的「话题解读」时，再填入你自己的模型接口即可。

## 它能做什么

- **今日推荐**：每天一批新词候选，按可信度分组，不想看可以逐条反馈（可撤销）。
- **趋势判断**：短期热度（3 天加速度）与长期趋势（26 周持续性）分开计算，
  区分「早期信号 / 短期爆发 / 长期主线 / 噪声热点」。
- **全局搜索**：`Ctrl+K` 搜本地词库与已接入来源，可扩展公共搜索接口。
- **循环记忆**：词卡可加入间隔重复复习计划，学过的新词再次升温时会提醒你。
- **来源自修复**：来源失效时自动查找同站点新订阅地址，跨域名更换需你确认。

## 隐私边界

- 所有能力都在本机运行：不提供云同步、云端任务或跨设备账号。
- 网络请求只用于读取你配置的来源内容与检查更新。
- 可选的 AI「深入解读」直接从你的机器调用你自己填的模型接口，中间没有第三方服务器。

## 已知边界
